Entry for the make.fun bounty [Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8).

`main.py` (Python 3.13, standard library only) writes a single one-line
out-of-office email auto-reply to `/output/entry.txt`:

> Out of office until the 30th. My fern Gary has a watering rota, a name tag and, as of Tuesday, my parking space.

Run it with:

```sh
python3 main.py
```
